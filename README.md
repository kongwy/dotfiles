# Dotfiles

Just a repository of my personal dotfiles.

## Setup

```bash
git clone https://github.com/kongwy/dotfiles.git ~/.dotfiles
cp ~/.dotfiles/local.zshrc.example ~/.zshrc.local
```

macOS:

```bash
ln -s ~/.dotfiles/macos.zshrc ~/.zshrc
```

Ubuntu:

```bash
ln -s ~/.dotfiles/ubuntu.zshrc ~/.zshrc
```
